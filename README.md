# Kun Tartibi — iPhone ilova

GitHub Actions bepul Mac serverida `KunTartibi.ipa` faylini avtomatik yig'adi.

1. GitHub'da yangi repo oching (masalan `kun-tartibi-ios`, Private bo'lishi mumkin) va shu papkadagi hamma narsani yuklang (`.github` papkasi ham!).
2. **Actions** bo'limi → "iOS ilovani yig'ish" → yashil belgi chiqqach, pastdagi **KunTartibi-ipa** ni yuklab oling (zip ichida .ipa).
3. Windows'da **Sideloadly** (sideloadly.io) o'rnating, iPhone'ni kabel bilan ulang, .ipa ni tashlang, Apple ID kiriting → Start.
4. iPhone: Sozlamalar → Umumiy → VPN va qurilma boshqaruvi → Apple ID'ingizga "Ishonish". Sozlamalar → Maxfiylik va xavfsizlik → Developer Mode → yoqish.
5. Bepul Apple ID bilan ilova 7 kun ishlaydi — Sideloadly orqali haftada bir qayta o'rnating (ma'lumotlar saqlanib qoladi).
